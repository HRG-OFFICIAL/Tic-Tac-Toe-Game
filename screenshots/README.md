# Screenshots

This folder contains screenshots of the Tic-Tac-Toe Game for documentation purposes.

## Current Screenshots

### ✅ Available
- **light-theme.png** - Game interface in light theme mode
- **dark-theme.png** - Game interface in dark theme mode

### 📝 Future Screenshots (Optional)
- **settings-modal.png** - Settings interface with all options
- **mobile-view.png** - Responsive mobile layout
- **game-history.png** - Move history with scrollbar

## Screenshot Guidelines

- Use high-quality PNG format
- Ensure good contrast and readability
- Show realistic game states (not empty boards)
- Include both light and dark themes
- Capture different screen sizes
- Show winning states and animations when possible

## How to Take Screenshots

1. **Desktop**: Use browser developer tools to set viewport size
2. **Mobile**: Use browser responsive design mode
3. **Settings**: Open settings modal and capture the interface
4. **History**: Play a few moves to show realistic history
5. **Themes**: Toggle between light and dark themes

## File Naming Convention

Use descriptive, lowercase filenames with hyphens:
- `light-theme.png` ✅
- `dark-theme.png` ✅
- `settings-modal.png` 📝
- `mobile-view.png` 📝
- `game-history.png` 📝
